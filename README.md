# Elytra Tracker Mod

## Intro
Elytra Tracker Mod is a Fabric mod for Minecraft 26.3 which enables a HUD for tracking elytra durability.
This mod and repo exist because I wanted this mod and making it felt like it would be a fun thing to learn.  It has.  Make no mistake, I'm not a java developer.  This is straight vibe coded, but I'm also learning things here.  If there ends up being any interest, I will certainly maintain and update things.  If not, this mod will get the same amount of attention Minecraft does in my life (variable.)

## Setup

* Clone the repository
* Open a command prompt/terminal to the repository directory
* run 'gradlew build'
* The built jar file will be in build/libs/
